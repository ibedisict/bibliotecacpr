# Como usar o índice HTML

1. Extraia todo o conteúdo do ZIP, preservando as pastas.
2. Abra `index.html` em Chrome, Edge ou Firefox.
3. Use a busca para localizar palavras no título, caminho ou texto integral.
4. Filtre por `status_juridico` e `tipo`.
5. Ordene por data, título ou pasta.
6. Clique em qualquer documento para ler o Markdown integral renderizado.
7. Use **Imprimir / PDF** para gerar uma cópia do documento exibido.

O arquivo funciona localmente e não depende de internet.
